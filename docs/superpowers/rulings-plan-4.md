## Notes for later plans

- Plan 5 (networks / ACL editor): `applyLegacyAclDefaults` (src/lib/networkCompat.ts, ported verbatim from upstream) fills `protocol: Any` / `action: Allow` into stored ACL rules whose enum value 0 was omitted by pbjson, so saving through the console can widen a dormant rule; the ACL editor must preserve omitted enums.
- Plan 6 (migration): never copy legacy VPN fields (`enable_vpn_portal`, `vpn_portal_*`) into member overrides — web v2.7.1 refuses to save such overrides and the member editor offers no switch to clear them (only 恢复默认).
- A new manual instance starts from upstream DEFAULT_NETWORK_CONFIG, whose listeners (tcp/udp 11010, …) can clash with the device's central instance; the clash shows as an instance error.
- 2.7-only flags (prefer_peer_relay, enable_udp_fec*) are offered to 2.6.4 cores; version-gating flags is not done.
- No client-side timeout on plain REST requests (only proxy-rpc has one); a stalled request keeps an editor or VPN dialog locked until navigation.
- Deferred UI polish: toast under a modal is not announced to screen readers (Reka aria-hidden); network_secret is not masked; duplicate 「手动实例」 heading on the instances page; instances table has no header row.
